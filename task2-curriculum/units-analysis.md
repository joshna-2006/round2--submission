The official program-structure page lists only course titles and credits, with **no units**. Units are only in course handouts, and I have **one** handout: DS401 Human Computer Interaction.

So this file has:
- **Part A:** a complete five-unit analysis of DS401, from the real handout

## Part A – DS401 Human Computer Interaction (3 credits, L3-T0-P0) [official handout]

*Note: DS401 appears in neither my Sem I–VII screenshots nor the official AI-track elective list, but the handout's CO–PO table covers the CSE (AI) programme. It may be an open elective. I use it here because it's the only real unit-level document I have.*

| Unit | Official topics (summary) | Roles | Coverage | Evidence from the handout | Recommendation |
|---|---|---|---|---|---|
| I | HCI basics; human memory and reasoning; input/output devices; VR/3D devices; paper printing and scanning | FS | Theory is fine; some content dated | Main textbook is Dix et al., 3rd ed., **2004** | UPDATE: cut printing/scanning, add mobile and touch input |
| II | Models and frameworks of interaction; ergonomics; interaction styles; WIMP | FS | Strong foundations | Sessions 9–16 | KEEP |
| III | Design process; scenarios; navigation and screen design; prototyping; usability heuristics; HCI patterns | FS, DA (dashboard design) | **Insufficiently practical** | L-T-P is 3-0-0, so no lab credits; assessment is assignments + mid-term + end-term only | UPDATE: assessed prototype + usability test |
| IV | Windowing systems; UI toolkits; evaluation methods; cognitive models | FS | Partial; tools dated | Toolkits named are **Tkinter and JavaFX**, not web UI | UPDATE: web UI tooling |
| V | Groupware; dialog design; AR/VR/mixed reality | AI (conversational UI) | Partial | No chatbots or AI-driven UI | UPDATE: add conversational/AI UX |

**The handout agrees:** its own "Gaps in the syllabus" section proposes adding "Chatbots, Emotion-aware UI, AI-driven UX design" and accessibility (WCAG).

**What I learned from doing this:** the course title alone ("HCI") sounds modern and practical, but the units show it is theory-only with 2004-era tools. **Title-based ratings can be wrong**, which is why I mark all my other alignment ratings as "title-only".
